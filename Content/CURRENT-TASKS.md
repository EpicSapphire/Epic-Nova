# 📋 PROJECT MANAGEMENT SYSTEM

Epic Nova development documentation is organized as follows:

### `CURRENT-TASKS.md`

Tracks what we are working on **right now**.

This should normally contain only immediate priorities and active tasks.

### `ROADMAP.md`

Tracks the **long-term development direction** of Epic Nova.

Future ideas and major systems belong here.

### `LAUNCH.md`

Tracks the **Version 1.0 Early Access launch process and verification history**.

Once Version 1.0 is fully verified, this document should remain as a historical launch record.

# 🔄 WORKFLOW

When beginning an Epic Nova development session:

1. Open `CURRENT-TASKS.md`.
2. Select the highest-priority unfinished task.
3. Complete and test the task.

5. Update `ROADMAP.md` only when the larger project direction changes.
